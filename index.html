Publication standard

How an instrument enters the code

  1. 01

    Classify

    Determine whether the record is founding authority, legislation, executive action, treasury policy, judicial material, agreement, filing, report, or reference.

  2. 02

    Authorize

    Record the issuing body, adoption act, signature, adoption date, effective date, and scope. Upload alone does not confer legal status.

  3. 03

    Assign

    Issue a permanent code in the format SOLN-CLASS-YEAR-NNNN. A code is never reused.

  4. 04

    Publish

    Commit the source document, metadata, checksum, and public entry. Later amendments link back to the original instrument.
