# State of Loc Nation Public Governance Registry

Parallel governance framework for community development, economic infrastructure, and restorative initiatives addressing historical and intergenerational inequities.

This repository now contains a GitHub Pages-ready public portal and a machine-readable governance registry.

## Main files

- `index.html` — public governance portal
- `registry.json` — authoritative public instrument index
- `governance/instrument.schema.json` — validation contract for every registry entry
- `governance/README.md` — identifier, classification, status, amendment, and publication rules
- `.github/workflows/pages.yml` — GitHub Pages deployment

## Identity

This is an independent SOLN public-benefit governance project. It is not an official website of the United States Government and does not claim a `.gov` designation.

## Publishing

GitHub Pages must be enabled with **GitHub Actions** as its source in the repository settings. Each push to `main` then publishes the current portal and document registry.
